## 1. 数据源配置

### 配置文件
- **位置**：`.vntrader/vt_setting.json`（优先当前目录，否则 `~/.vntrader/`）
- **关键字段**：
  ```json
  {
    "datafeed.name": "akshare",      // 数据源名称（akshare / tushare / rqdata ...）
    "datafeed.username": "",          // AKShare 无需填写
    "datafeed.password": "",          // AKShare 无需 Token
    "database.name": "sqlite",
    "database.database": "database.db"
  }
  ```

### 数据源对比

| 数据源 | 费用 | 频率限制 | 品种 | 指数 |
|--------|------|----------|------|------|
| **AKShare (新浪)** | 免费 | 无 | 股票/期货主力 | ❌ 需 tushare |
| **AKShare (东方财富)** | 免费 | 无 | 股票/期货 | ❌ 部分网络环境不通 |
| **Tushare 社区版** | 免费 | 极严(1次/分钟) | 有限 | ✅ |
| **Tushare Level 1** | 200元/年 | 200次/分钟 | 全面 | ✅ |

### 切换数据源
编辑 `.vntrader/vt_setting.json` → 改 `datafeed.name` 即可，无需改代码。

## 2. 自定义 Datafeed 插件

### 文件结构
```
vnpy_akshare/
├── __init__.py              # 导出 Datafeed 类
├── akshare_datafeed.py      # 核心实现
└── setup.py                 # pip install -e .
```

### 关键接口
```python
from vnpy.trader.datafeed import BaseDatafeed
from vnpy.trader.object import BarData, HistoryRequest

class Datafeed(BaseDatafeed):
    def init(self, output=print) -> bool: ...
    def query_bar_history(self, req: HistoryRequest, output=print) -> list[BarData]: ...
    def query_tick_history(self, req: HistoryRequest, output=print) -> list[TickData]: ...
```

### 加载机制
`vnpy.trader.datafeed.get_datafeed()` 读取 `SETTINGS["datafeed.name"]`，动态 `import_module(f"vnpy_{name}")`，调用 `module.Datafeed()` 实例化。

### 超时与重试
用 `ThreadPoolExecutor` 包装网络请求，设置 45-60s 超时 + 3 次指数退避重试，避免 AKShare 底层挂死。

### 日期类型陷阱
- AKShare 新浪接口返回 `datetime.date`（无 `to_pydatetime()`）
- AKShare 东方财富返回 `pd.Timestamp`
- 统一处理：
  ```python
  if isinstance(val, str):       dt = datetime.strptime(val, "%Y-%m-%d")
  elif isinstance(val, date):    dt = datetime.combine(val, datetime.min.time())
  else:                          dt = val.to_pydatetime()
  ```
- 日期比较统一用 `pd.Timestamp(start.replace(tzinfo=None))` 避免时区冲突

## 3. 数据下载

### 脚本用法
```bash
python download_data.py              # 默认下载最近4年日线
python download_data.py --years 5    # 最近5年
python download_data.py --start 2020-01-01  # 从指定日期开始
```

### 数据库
- **格式**：SQLite（`.vntrader/database.db`）
- **查看数据**：`python -c "from vnpy.trader.database import get_database; ..."`
- **重建**：`rm .vntrader/database.db && python download_data.py`

### 期货主力连续合约
- vnpy 使用 `888` 后缀表示主力连续（如 `RB888.SHFE`）
- 新浪 API 使用 `0` 后缀（如 `RB0`）
- datafeed 自动映射 `888 → 0`，用 `futures_main_sina` 获取多年历史
- 普通合约（如 `RB2509`）只有几个月的数据（合约生命周期）

### 回测数据量建议
| 策略类型 | 建议时间 | 日线条数 |
|---------|---------|----------|
| CTA 趋势 | 3-4 年 | ~750-1000 |
| 均值回归/套利 | 2 年 | ~500 |
| 机器学习选股 | 5 年+ | ~1250+ |

## 7. 已知问题 & 修复

### vnpy_datamanager 不支持周线
- **文件**：`.venv/lib/python3.12/site-packages/vnpy_datamanager/ui/widget.py`
- **修复**：在 `INTERVAL_NAME_MAP` 和 `refresh_tree()` 循环中添加 `Interval.WEEKLY`
- **注意**：`pip install --upgrade vnpy_datamanager` 会覆盖此修复

### AKShare 东方财富 API 不通
- 错误：`RemoteDisconnected` / `Connection aborted`
- 原因：`push2his.eastmoney.com` 在某些网络环境下被阻断
- 解决：切换到新浪 API（`stock_zh_a_daily`、`futures_main_sina`）
